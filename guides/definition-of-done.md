# Definition Of Done

## End-Of-Day Checklist

- [ ] Problem statement and one-day scope are documented
- [ ] Roles and parallel work split are clear
- [ ] Architecture or implementation plan exists
- [ ] A working prototype or credible implementation is available
- [ ] Tests or validation evidence are captured
- [ ] Setup notes or usage instructions exist
- [ ] A PR-style summary is written
- [ ] A demo script is prepared
- [ ] A Codex workflow log is filled in
- [ ] Known limitations and next steps are honest

## What "Credible Implementation" Means

It does not have to be production-ready. It should be:

- demoable
- understandable
- scoped honestly
- backed by some validation

## Final Sanity Check

If time is short, prioritize:

1. one strong demo path
2. honest limitations
3. visible evidence of AI-native workflow

# Participant Setup

## Bring

- laptop
- charger

## Access And Tools

- Install a local IDE, preferably VS Code unless instructed otherwise
- Install the Codex IDE extension if available
- Confirm ChatGPT / Codex access
- Confirm GitHub access
- Complete any MFA or login requirements before the event

## Repo Setup

- Clone or fork the starter repo
- Open it locally
- Read `README.md` and `AGENTS.md`

## Dev Environment Checks

- Verify local runtime support for the stack you expect to use
- Confirm package manager or language tooling works locally
- Test one simple project run if you already know your stack

## Recommended Pre-Event Checks

- Verify internet access if your idea needs external services
- Check whether API keys or platform accounts are required
- Download local models in advance if using Ollama or similar
- Make sure screen sharing or demo output works

## Fallback Advice

- If Codex access fails, use the Markdown files as manual team templates
- If local setup fails, switch to a lower-risk stack such as a CLI, Streamlit app, or mock-driven prototype
- If integrations fail, narrow the demo to a believable local slice
